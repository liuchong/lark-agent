# Shared work classification

When work kind controls tool availability, turn budgets, and terminal evidence
checks, routing and runtime validation must use one shared classifier.
Duplicated keyword tables drift: routing can label a source investigation as a
simple question while runtime still expects code evidence, leaving the model
without the tools needed to satisfy the terminal gate.

Use exact failed production wording as an integration fixture. Cover every
relevant intake shape, such as assistant private chat and native group mention,
and assert the selected work kind and priority before testing the model loop.
